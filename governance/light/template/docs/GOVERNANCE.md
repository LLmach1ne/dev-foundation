# Governança — Light

Este projeto utiliza o nível de governança **Light** da DEV FOUNDATION.

Para mudanças de baixo risco, mantenha requisitos e critérios de aceite suficientes para execução, realize as verificações aplicáveis e obtenha homologação humana da entrega e de suas evidências. Use documentação e processo somente na medida em que agregarem valor.

Consulte os documentos Base relevantes:

- `docs/PRODUCT.md`
- `docs/REQUIREMENTS.md`
- `docs/QUALITY.md`

O padrão completo está em `docs/GOVERNANCE_STANDARD.md` na Foundation de origem registrada em `FOUNDATION.lock`.
