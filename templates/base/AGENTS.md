# Instruções do projeto

- O repositório do projeto é a fonte persistente da verdade.
- Leia `docs/REQUIREMENTS.md` e `docs/ARCHITECTURE.md` antes de mudanças materiais.
- Não altere silenciosamente requisitos aprovados, arquitetura documentada ou decisões registradas apenas para facilitar a implementação.
- Preserve o trabalho existente, incluindo alterações não relacionadas do usuário, e mantenha as mudanças pequenas, focadas e revisáveis.
- Evite complexidade e dependências sem necessidade concreta.
- Execute e reporte as verificações aplicáveis antes de declarar sucesso.
- Não execute operações Git destrutivas sem autorização explícita.
- Não faça commit ou push automaticamente.
