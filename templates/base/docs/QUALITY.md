# Qualidade

## Definition of Ready

Uma tarefa está pronta quando possui objetivo, requisitos relacionados, comportamento esperado, restrições, critérios de aceite e estratégia de verificação suficientes para execução sem decisões importantes implícitas.

## Definition of Done

Uma alteração está concluída quando foi revisada, atende aos requisitos relacionados, passa pelos quality gates aplicáveis e não possui falhas conhecidas incompatíveis com a entrega.
