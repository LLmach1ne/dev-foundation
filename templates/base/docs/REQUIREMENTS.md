# Requisitos

## Convenção de IDs

Use IDs estáveis no formato `[TIPO]-[DOMINIO]-[NUMERO]`, por exemplo: `REQ-PROD-001`.

## Requisitos funcionais

- `[REQ-PROD-001]` [DESCREVA_O_COMPORTAMENTO_VERIFICAVEL]

## Requisitos não funcionais

- `[RNF-PROD-001]` [DESCREVA_A_QUALIDADE_OU_RESTRICAO_VERIFICAVEL]

## Regras de negócio

- `[RN-PROD-001]` [DESCREVA_A_REGRA_DE_NEGOCIO]

## Critérios de aceite

- `[CA-PROD-001]` [DESCREVA_A_EVIDENCIA_NECESSARIA_PARA_ACEITACAO]
